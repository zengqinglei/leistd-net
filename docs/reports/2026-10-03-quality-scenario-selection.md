## 缺陷检测与评审决策

- 完整静态 30/30、actionlint v1.7.12、官方 Skill 校验通过。
- 实际 YAML 执行夹具覆盖范围路径、Unicode/空白、删除/rename、多提交、浅克隆/补取、失败 diff、非 PR/复用；实际汇总拒绝静态及每个必要作业 failure/cancelled/缺失/错误 skipped，以及非法计划身份。删除静态成功检查可重现假绿，恢复后拒绝。
- 选测夹具实际 Git 输入与六种产品两侧生成对照；默认/full/dirty 保守回退；错 SHA/模式/档位、缺场景和各阶段跳过/失败/伪 pass 均拒绝。评审新增的未知 source/modifier 负例在 base/head 都包含规则，差异仅源码，确实触发显式守卫。
- 三类源码预检变异（未知条件、条件内 InternalsVisibleTo、同步等待动态连接）由原检查器、默认人工矩阵和接替静态入口拒绝；CI 可继续生成但汇总失败。删除任一预检登记及人工使用跳过开关拒绝；28 条实际命令记录符合预期，合法对照恢复绿。
- 实际 C# 编译缺陷注入：原完整矩阵与新后端局部矩阵都因同一 `CS0103 MissingQualityBackendSymbol` 非零退出。两次 55.509/91.124 秒是失败路径观测，不能作为性能收益。
- 未选包 XML 缺失、漏包、缺候选依赖、未知种子、full 裁剪计划均拒绝，恢复内容后通过。
- 实际文档缺失 Skill 引用令静态和必过汇总同时失败，动态 skipped 不造成假绿；默认 full/候选与 caller SHA 不同的真实复用及容器通过。

## 验收边界

实现与缺陷拒绝责任均已完成上述验证，最后 SHA 的质量结果与 Claude 复审继续在 MR 收敛。**PR 墙钟中位 ≤510 秒尚未稳定验收**：不同候选的一次观测不能当相同候选的独立重复样本，也不能用同时触发专用验证造成的排队估算日常 SLA。首次真实业务局部 PR 仍应核对它的计划与回执；本轮未实测业务功能开发的端到端耗时。发布或合入 SHA 必须执行它自己的完整质量责任。
