# 全局导航与过渡进度

状态：已完成 · 风险档：中

## 1. 需求

懒加载路由和词条 scope 在慢网络下缺少统一等待提示；项目自发的长过渡也需要同一个进度入口。2026-11-04 用户确认实施模板级全局不定态进度条；同日调整分工为 Claude 实施与合并，Codex 审查方案与代码，审查通过且 CI 全绿后合并。

| 要求 | 验收（Given / When / Then） | 覆盖 |
| --- | --- | --- |
| 统一延迟与收尾 | Given 路由或手动占用，When 未满 300ms，Then 不显示；满 300ms 仍在等待才显示，最后释放时立即隐藏 | 服务与组件 spec |
| 引用计数 | When 多次 begin 或路由与手动叠加，Then 每份独立释放，重复释放无副作用，最后一份结束才隐藏 | 服务 spec |
| 路由接续 | When 导航被新导航取代或被重定向（路由先发取消、再发新导航的开始），Then 只占一份计数，进度条不断开也不重新计时；End、Error、Skipped 与其他取消后释放 | 服务 spec（含真实路由用例） |
| 展示位置 | Given 布局内或跨布局的懒加载等待，When 导航未完成，Then 进度条显示在当前布局顶栏下方的内容区顶部；没有布局的页面显示在视口顶部；页面骨架与按钮忙碌态保留 | 组件与根组件 spec、浏览器验收 |
| 无障碍与本地化 | When 隐藏，Then DOM 无 progressbar；显示时有名称，本地化开关两种形态可编译；减少动效时显示静态整条 | 组件 spec、两场景生成与构建 |

服务使用 NavigationProgressService.begin 返回幂等释放函数，所有调用统一延迟；组件使用 CLI 生成的 Spartan progress，两个布局在顶栏与内容之间各挂一份，根模板保留一份视口兜底，内容区实例登记后兜底让位。轨道用主色 20%，滑块改用自有关键帧：官方 indeterminate 从视口外起步、4s 一程，短于约 1s 的等待看不到滑块。

2026-11-04 首版合入后，用户确认把进度条从视口顶部移到内容区顶部，颜色一并优化。初始包体积以相同生产构建前后对比，差异及来源记录在实施报告。

## 4. 结果

- resource 与 resource-localization 两种场景生成后，定向服务、组件与根 spec 分别 22/22、26/26 通过；lint、i18n 检查与生产构建通过；仓库静态闸门 50 项与读取成本闸门通过。
- 路由接续：Angular 22 在被取代的导航结束时先发 `NavigationCancel`（SupersededByNewNavigation），新导航随后才发 `NavigationStart`。服务对被取代与重定向的取消不释放占用；把它们改回释放后，含真实路由在内的 3 条用例失败。
- 浏览器验收（Mock、懒加载 chunk 人为延迟 800ms）：
  - 懒加载导航与跨布局导航（工作空间 → 管理平台）都在 300ms 后出现进度条，导航完成后消失；跨布局期间进度条不中断；
  - 慢导航中途改点另一项时，进度条连续显示；
  - 进度条带无障碍名称与不定态动画，减少动效时动画为 none。
- 初始包：相同 resource 生产构建，Initial total 原始字节 1,130,369 → 1,134,735（+4,366，约 0.39%），其中主 JS +4,322、CSS +44，来源为进度服务与组件以及 Spartan progress。
- 位置与颜色调整（第二个 PR）：resource 与 resource-localization 两种场景定向 spec 23/23、27/27，本地化场景前端全量 897 条通过；lint、i18n、生产构建、静态闸门 50 项与读取成本闸门通过。浏览器验收（Mock、网络限速）：管理平台与工作空间都在约 330ms 后只出现一条进度条，上缘与顶栏下缘重合，宽度等于内容区；轨道为主色 20%，滑块为 1.5s 自有关键帧。
