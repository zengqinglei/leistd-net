# 公开内容、弹窗焦点、文档增量与组件升级

状态：进行中 · 风险档：高

## 1. 需求

用户于 2026-11-01 确认跨 Framework、Template、Skill 与 CI 的本轮范围，策略复审通过后实施。

| 条目 | 验收标准 | 验证 |
| --- | --- | --- |
| 公开内容 | 给定全部跟踪文件与公开 PR 文字，清理下游名称、内部服务与专属业务信息后，技术结论与理由保留；后续引入相同表述会失败 | 现有术语闸门、全仓扫描与公开文字审稿 |
| 弹窗焦点 | 给定两档视口的三类表单，首尾及首末列控件聚焦时，外扩 3px 的焦点环完全在所有裁剪祖先的可见区域内；正文与标题左缘误差不超过 0.5px，无横向滚动，页脚可达 | 实际生成项目的浏览器几何测量与截图 |
| 组件升级 | Spartan Brain/CLI 正式版 1.9.0 与 Helm 同步；逐项审视定制，官方入口替代本地变通，三种前端形态无回归 | 全量测试、lint、生产构建、定制闸门及两档浏览器回归 |
| 文档增量 | 同一 PR 同基线的前一候选已通过，新增文档时只执行当前文档责任并承接成功来源；基线、来源或输入无法证明时回退原 PR 计划 | 质量计划、汇总核验与反例；本 PR 实际文档提交观察 |

不改 Git 历史、正式版发布流程和下游项目。公开文字改写须等最终候选审查通过；合并也须最终候选审查通过且 CI 全绿。

## 2. 方案

公开内容扫描复用现有术语闸门，词表为唯一豁免，不继承历史规格豁免。示例使用通用服务名，保留连接名归一化、多服务分库、并发与审计断言。

弹窗内边距由 Helm 的同一变量定义。滚动正文以等量负外边距与内边距扩展裁剪边界，表单用最小高度约束收缩；保留单层滚动和固定页脚。带按钮的徽章保留内部文字截断，外壳不裁剪子按钮焦点环；其他裁剪容器按实际控件与留白复核。

直接 PR 继续验证合并候选。文档增量只在 synchronize 中启用，固定同仓库、同 PR、同 workflow 对前一 head 的最新运行与 attempt，通过该次计划构件与成功汇总核对来源。目标分支基线必须相同，分支增量和合并候选完整差异均须属于已有文档分类。计划记录当前 head/base/候选、来源和责任链，汇总核验后才输出成功。证据缺失、失败、未知输入、目标分支前移或非祖先均回退原计划。合并后与发布候选计划不变。

Spartan 按官方更新指南升级两个 manifest 及锁文件，使用同版 CLI 生成 Vega 基线，逐组件三方合入。Avatar、OTP 适配新指令；Sheet 通过官方 closeLabel 接共享译文，删除对应 Helm 定制；OTP 使用显式原生 input 和 slotPattern，删除内部 DOM 操作，保留经渲染后执行的同轮清空同步。保留仍无官方替代的触屏、无障碍、组字与关闭闸门改动。升级浏览器验收发现确认框默认 ID 冲突与触发 Esc 继续冒泡关闭新确认框，应用层通过官方 id 入口和共用关闭部件阻止原事件继续传播。两项均补真实浮层的先红后绿回归。

## 4. 结果

四项实现与第一轮审查修复已纳入本 PR。公开内容闸门覆盖历史规格与全部跟踪文件，任务示例、XML 与编译桩统一为通用账务示例；保留归一化、排序、分库与审计语义。公开文字待改稿已修正重复词、列表与空洞指代，链接保持原样。

Spartan Brain/CLI 与两个条件包变体锁定 1.9.0，40 个 Helm 组件按同版官方 CLI 基线比较合入。Sheet 改用官方 closeLabel，OTP 改为显式原生 input；保留有回归依据的渲染后清空同步。升级验收发现的确认框 ID 冲突及 Esc 传播关闭新确认框均已修复，两项新增真实浮层回归先失败后通过。

本地受影响框架测试、73 个候选包及隔离消费、149 个文档块编译、四个代表场景生成、control、静态闸门和原读取预算均有通过证据。三种前端形态完成全量单测、lint 与生产构建。两档视口的八组几何测量保持标题对齐、单层滚动、无横向滚动和页脚可达；关闭四入口、未保存确认、延迟保存及命令面板组字与可访问名均已回归。

CI 来源与 attempt 证据复用公共实现，文档职责清单只有一处；stable 70 个来源反例与 PR 25 个回退反例通过，真实汇总能拒绝责任与 PR 身份篡改。实际文档增量观察、公开文字改写、最终 head 审查、合并与 beta 结果以本 PR 的后续交付记录为准。历史提交与 tag 保留。
