# 操作指南索引

> `guides/` 存放**可复用的操作步骤**（how-to），区别于 `standards/`（长期规则）。按任务分流：

| 你要做什么 | 指南 |
| --- | --- |
| 初始化/创建前端项目 | [`create-app/frontend-create.md`](./create-app/frontend-create.md) |

| 前端 Mock 开发 | [`frontend/mock-development.md`](./frontend/mock-development.md) |

- `create-app/`：**从零创建**项目/骨架时的一次性初始化步骤。
- `frontend/`：项目**已创建后**，前端日常开发中的专项 how-to。
