# 环境交付

先确认目标环境、产物版本和用户要求的阶段。优先参考项目部署文档及最近同类交付；缺失时从实际流水线、产物、配置、迁移入口和健康检查建立事实。

1. 核对候选提交、产物组成与版本对应关系、配置和密钥来源、成功判据及回滚条件；涉及数据时核对备份、兼容性和恢复能力。
2. 按当前项目确认部署与迁移顺序；存在自动迁移时不重复执行，旧版本并行运行时核对兼容性。
3. 外部操作前核对现有授权是否覆盖目标、环境和动作；未覆盖时再询问。按项目流程执行，并验证产物版本、健康、日志、数据状态与核心业务路径。
4. 失败时依据实际状态保护数据并恢复；应用回滚与数据恢复分别判断。报告版本、环境、验证结果和未解决风险。已验证且会复用的环境规则更新到项目部署文档或最小说明，并登记到现有文档索引。
